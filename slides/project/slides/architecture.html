Why ASP.NET Core MVC, not WPF

Round 1 interview, verbatim

“I'm hoping in the next 12 months, all of it will be in C sharp and we'll be running on Razor.”

Job description

“Work with ASP.NET, VB.NET and/or C#” · “Develop customer-facing interfaces”

Why not WPF / MVVM

WPF is Windows-only — it can't build or run on my Mac. I'd have shipped code I could never actually test, which conflicts with “test your work and take responsibility for it.”

Chosen instead

ASP.NET Core MVC (C#, Razor views) — cross-platform, matches BookingTimes' stated direction, and Controller / View / Model stay cleanly separated.
