What was asked, and what I built

Adam's brief

Write a small .NET program that turns a cheque amount into words — e.g. 1234.56 becomes “One thousand, two hundred and thirty-four dollars and fifty-six cents.”

Return the code, a note on testing and edge cases, and a good UI. AI use expected.

Delivered

  • ASP.NET Core MVC app with a live, styled UI
  • Conversion logic in its own tested class library
  • 48 automated tests, 95.6% line coverage
  • Validation for negative, non-numeric, oversized input
  • README documenting every edge case considered
